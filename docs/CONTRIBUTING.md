# Contribuição

Obrigado por querer contribuir! Siga estas regras básicas:

1. Fork e branch
   - Faça fork do repositório (se não tiver push direto).
   - Crie uma branch com nome descritivo: `feature/nome-curto` ou `fix/nome-curto`.

2. Estilo de commit
   - Use mensagens claras e no estilo: `feat(...)`, `fix(...)`, `chore(...)`, `docs(...)`.

3. Testes
   - Adicione testes quando modificar lógica crítica.
   - Rode a suíte antes de abrir PR: `npm test`.

4. Pull Request
   - Abra PR direcionado ao branch `main` (ou outro branch de integração do projeto).
   - Descreva as mudanças e o motivo.

5. Revisão
   - Resolva comentários da revisão e reforce testes quando necessário.
